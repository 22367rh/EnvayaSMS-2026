How to get set up

  1. Create an account and sign in from the console at /console. Registration mints a login password plus a separate device shared secret.
  2. Copy your device configuration. On the Dashboard you'll see a Server URL like http://<host>:<port>/<user>/gateway and a shared secret.
  3. Point each Android device at it. In EnvayaSMS settings set Server URL to that /<user>/gateway address and Password to the shared secret.
  4. Watch it come alive. Devices appear under Devices; read messages in Inbox/Outbox, per-number Conversations, and battery/volume charts under History.

The console is an internal ops tool served over HTTP. Terminate TLS at a proxy in production so the session cookie can be marked Secure. Your login password and your devices' shared secret are intentionally different values — changing one never breaks the other.
